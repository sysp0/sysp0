## About me

I’m Reza, an engineer who enjoys turning repetitive work into dependable systems. I started in network quality testing, where writing Python automation led me into backend development. From there I learned to ship and operate the software I built, then moved into data engineering. Today I’m building data infrastructure and learning how to apply AI to real product problems.

I care about work that is useful to a team: tests that can be repeated, releases that can be trusted, and data or AI outputs people can trace and act on. I like learning by building, then leaving each system a little easier to run than I found it.

## What I’ve built

- **Network quality:** researched static-routing scenarios, tested routers and switches before release, and documented networking technologies for the QC team.
- **Backend and automation:** built reusable Python packages and a Django REST Framework platform for automated testing, with Celery and RabbitMQ for scheduled and asynchronous jobs.
- **Delivery and operations:** created GitLab CI and Jenkins pipelines for Dev, Staging, and Prod. Parallel network-test pipelines cut a typical run from about 30 minutes to about 10, even with a limited pool of physical devices.
- **Data platform:** designed a Modern Data Stack connecting 10+ sources. It combines CDC and streaming, dbt models, Apache Doris for real-time analytics, and Apache Iceberg for historical data, with lineage, quality checks, access controls, and internal APIs.
- **Applied AI:** building LLM workflows that structure support conversations and summarize hotel reviews for product APIs. I focus on treating models as pipeline steps, with retries, rate limits, cost, and tracing in mind.
