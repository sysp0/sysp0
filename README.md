## 📌 About Me

I'm Reza, an engineer who enjoys building useful systems and making them easier to run. I started in network quality testing, where automating repetitive work with Python led me into backend development. I then took responsibility for shipping and operating those systems, moved into data engineering, and am now learning to apply AI to real product problems.

I care about reliable delivery, traceable data, and practical results for the people using what I build. My work has included:

- Automating network tests and QC workflows with Python.
- Building Django REST APIs and background jobs with Celery and RabbitMQ.
- Creating GitLab CI and Jenkins pipelines; parallel testing cut a typical run from about 30 minutes to about 10.
- Designing a data platform for 10+ sources, with CDC, streaming, dbt models, real-time analytics, historical storage, lineage, and access controls.
- Building LLM workflows to structure support conversations and summarize hotel reviews for product APIs.
